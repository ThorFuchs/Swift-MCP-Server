# ``MCPSkills``

Advertise skill directories and their files through the Skills extension.

## Overview

Construct an immutable ``SkillCatalog`` from host-selected sources. The catalog validates its definitions and exposes extension registration and resource providers. Files are described with size and SHA-256 metadata. Configure scopes and listing limits for the host's trust boundary.

The extension publishes data and resource identifiers; it does not execute instructions or grant access outside the registered resources.
